二、我们收集的信息

我们仅收集为实现产品功能所必需的最少信息：

2.1 您主动提供的信息

  • Apple ID 登录信息：当您使用"通过 Apple 登录"时，我们获取 Apple 提供的用户标识符、显示名称和邮箱地址（如您选择共享）。
  • 邮箱或手机号：当您选择邮箱验证码或短信验证码登录时，我们处理您提供的邮箱地址或手机号，用于登录验证与账户管理。
  • 昵称：您可以设置在社区中显示的昵称。
  • 用户创作内容：您上传到社区的拼豆作品图片和描述。

2.2 我们自动收集的信息

  • 照片/相机：仅在您主动选择照片或拍照时访问，用于创建拼豆图纸。我们不会在后台访问您的相册。
  • 本地存储：项目数据（拼豆图纸、进度）存储在您设备本地。
  • 应用偏好设置：主题、语言等设置保存在设备本地（UserDefaults）。

2.3 我们不收集的信息

  • 我们不收集设备标识符（IDFA/IDFV）
  • 我们不获取设备的精确定位
  • 我们不收集通讯录、短信、通话记录
  • 我们不使用第三方广告跟踪 SDK；自建统计见第 2.4 节，网站 Cloudflare Web Analytics 见第 2.5 节
  • 我们不跟踪您在其他 App 中的活动

2.4 自建使用情况统计

我们使用自建统计功能了解创作和社区功能的使用情况，例如创作开始、编辑完成、浏览作品、评分、下载、登录及操作失败，以发现功能中断和改进使用体验。统计可包含事件名称与时间、功能选项、数量或时长区间、应用版本、系统版本和平台；不包含作品正文、图片内容、邮箱或手机号。

登录用户的事件可与本服务的用户 ID 关联。服务端仅在账户记录确认您已接受包含统计说明的 1.1 或更新版本条款后接收这些事件。iOS 还遵循本机“使用情况统计”开关，该开关默认开启；Web 自建统计默认关闭，需您在接受条款后为当前账号和浏览器主动开启，不会补发开启前产生的事件。

在 iOS，未登录会话在本机统计开启时仅使用内存中生成的会话标识，不附带用户 ID；该标识在 App 进程结束后失效，不写入设备存储，不用于跨 App 或跨启动识别设备。

您可在 iOS“我的 → 使用情况统计”或 Web 个人页关闭自建统计。关闭会停止此客户端后续自建事件上报并清空尚未发送的事件，不影响核心功能；不同设备或浏览器的开关分别管理。关闭不自动删除已收到的事件，删除途径见第七节。

2.5 网站 Cloudflare Web Analytics

网站使用 Cloudflare Web Analytics，由 Cloudflare 自动向网页注入统计脚本，用于网站访问和浏览器性能统计。当前配置为启用并排除欧盟访客。此功能独立于第 2.4 节的自建统计开关；关闭自建统计不会关闭网站的 Cloudflare Web Analytics。

2.4 Self-Hosted Usage Analytics

We use self-hosted analytics to understand creation and community workflows, such as starting a project, completing edits, viewing artwork, rating, downloading, signing in and encountering an operation failure. Events help identify interrupted workflows and improve the experience. They may include an event name and time, feature choices, count or duration ranges, app version, OS version and platform. They do not contain artwork text, image content, email addresses or phone numbers.

Signed-in events may be associated with your user ID for this service. The server accepts them only after the account record confirms acceptance of terms version 1.1 or later, which includes the analytics explanation. iOS also follows its local Usage Analytics switch, which is on by default. Self-hosted Web analytics is off by default and requires you to enable it for the current account and browser after accepting the terms. Events generated before enabling it are not replayed.

On iOS, when the local analytics setting is enabled while signed out, events use only a session identifier generated in memory, without a user ID. It expires when the app process ends, is not written to device storage, and is not used to identify a device across apps or launches.

You can turn self-hosted analytics off under Profile → Usage Analytics in iOS or on the Web profile page. This stops future self-hosted event reporting from that client and clears unsent events without affecting core features. Switches are managed separately on each device or browser. Turning analytics off does not automatically delete events already received; deletion options are described in Section 7.

2.5 Cloudflare Web Analytics on the Website

The website uses Cloudflare Web Analytics. Cloudflare automatically injects its analytics script into web pages to measure website visits and browser performance. The current configuration enables this service while excluding visitors from the EU. It operates independently of the self-hosted analytics controls in Section 2.4. Turning off self-hosted analytics does not turn off Cloudflare Web Analytics on the website.
